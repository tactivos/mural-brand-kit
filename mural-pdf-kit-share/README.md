# Mural PDF Kit Share Bundle

This bundle is meant to help someone get started in Cursor with:

- the Mural brand guidelines kit
- the Mural PDF generator kit
- the current project rules used in this repo
- a working starter, pattern library, and example

## Included Files

- `.cursorrules` — project-specific rules used in this repo
- `mural-brand-guidelines.html` — brand guide reference
- `MURAL-BRAND-SKILLS-KIT.md` — brand guidance and working context
- `mural-pdf-generator-starter.html` — starting file for new PDFs
- `mural-pdf-generator-pattern-library.html` — visual reference of available patterns
- `mural-pdf-generator.html` — filled example PDF
- `PDF-GENERATOR-KIT.md` — operating guide
- `PDF-GENERATOR-SPEC.md` — source of truth for the kit
- `Mural_Wordmark_Multicolor.svg` — logo asset used by the kit
- `cert-logos/` and `enterprise-logos/` — local example assets

## Recommended Workflow

1. Open this bundle in Cursor.
2. Make sure Bill's AI coding rules are installed in Cursor:
   [chickensintrees/ai-coding-rules](https://github.com/chickensintrees/ai-coding-rules)
3. Review `mural-brand-guidelines.html`, `PDF-GENERATOR-KIT.md`, and `mural-pdf-generator-pattern-library.html`.
4. Provide a copy doc or paste source content into Cursor.
5. Generate the first HTML draft automatically using `mural-pdf-generator-starter.html` plus the kit guidance.
6. Review the HTML in the browser.
7. Edit and refine in Cursor.
8. Export with `File > Print > Save as PDF`.
