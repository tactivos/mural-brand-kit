Pattern library

Pattern library reference document

This document is a visual reference for the patterns established in the PDF generator kit. Use it to review the available pattern types, understand how they are intended to behave, and guide future PDF generation and refinement.

How to use this reference

  1. Load the Mural brand guidelines kit and the PDF generator kit into Cursor, and make sure Bill's AI coding rules are active.
  2. Provide a copy doc or paste source content into Cursor, then generate the first HTML draft automatically using the established kit patterns.
  3. Use this reference to understand what patterns exist, review how they behave, and refine the generated HTML before exporting the final document as a PDF.

Core editorial patterns

This section shows the foundational editorial content types used most often in a print-first PDF: headline, section heading, body copy, bullets, and numbered lists.

Pattern: Title and subtitle

Use this pattern when the source hierarchy calls for a named title followed by a compact supporting line such as a plan, audience, or document type.

Example

Member pricing

Enterprise plan

Pattern: Headline

Use this pattern for a serif headline with a supporting paragraph when the content needs emphasis but should remain clearly below the display title. It can work for title-less opener headlines, internal proof statements, or pricing promises.

Example

Predictable and straightforward pricing — no catches, no surprises.

Use this tier for internal proof statements, pricing promises, or other editorial moments that need emphasis inside the body narrative without reading like the page title.

Pattern: Section heading and body copy

Use this pattern when a section heading and body copy should work together in one section. Consecutive body copy paragraphs are spaced var(--body-space) (6.5pt) apart.
