Pattern library

Pattern library pages for review, refinement, and approval.

This first-pass library turns the written kit into fixed-page visual patterns. Each page is a draft review surface, not a final approved template. The goal is to evaluate hierarchy, spacing, and pattern usefulness before promoting any module into the recommended set.

Editorial Comparison Access matrix Stat / proof Image / screenshot Supporting

Review these patterns one by one. Adjust brand tone, spacing, hierarchy, and usage rules here before they become normalized building blocks for the generator kit.

Starter role

A minimal file for new PDFs. It should stay generic, stable, and easy to duplicate.

Pattern-library role

A draft catalog of optional modules. It should be explicit, reviewable, and visually labeled.

Example role

A finished subject-matter piece that demonstrates how approved patterns work in a real document.

Approval mindset

Treat every pattern as provisional until it is tuned for brand and added to the recommended pattern set.

Core editorial patterns

These modules cover the most common narrative layouts: a clean opener, a proof strip, a two-column body section, and a compact bullet-grid treatment for capabilities or themes.

Pattern

Editorial opener

Use for the first page of a leave-behind or one-sheet. Supports a concise topic label, a strong headline, and a deck designed for print reading.

Pattern

Opener with proof strip

Add a short proof line, narrative, or customer logo strip directly under the opener when the first page needs credibility or orientation.

Pattern

Two-column narrative page

Good for an explanatory section where the left column carries narrative setup and the right column breaks ideas into four smaller sub-points.

Pattern

Bullet-grid / capabilities page

Use short subheads with body-style bullets. This works well for capabilities, controls, benefits, or grouped features, but should stay calm and editorial rather than "horsey."

  • Body-size bullet copy
  • Optically even spacing
